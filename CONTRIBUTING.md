# Contributing

Build with the matching MSVC/Qt kit and run `scripts/Build.ps1 -RunChecks` before submitting changes. Keep automated checks free of hardware commands. Do not broaden the motherboard allowlist without documented hardware validation.

For bug reports, include plugin/OpenRGB/Qt versions, motherboard model, selected mode/speed/stages, visible error text, and whether another motherboard control application was running. Remove personal paths and unrelated details from published logs.

Register-mapping changes should cite upstream source or reproducible hardware evidence. Keep access serialized and ensure configuration mode is exited on failures.
